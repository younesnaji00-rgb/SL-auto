# **App Name**: DashFlow Admin

## Core Features:

- Interactive Dashboard Layout: Implement the responsive main application shell, including a collapsible sidebar with icon-only mode and a dynamic top navigation bar featuring breadcrumbs.
- Dynamic Navigation Menus: Provide a comprehensive, icon-based sidebar navigation with key sections ('Tableau de bord', 'Dossiers', 'Utilisateurs', 'Compagnies') and a 'Compagnies' sub-section that dynamically lists client companies with visual indicators.
- Intelligent Global Search Tool: Integrate a Cmd+K style global search feature powered by generative AI, capable of interpreting natural language queries to quickly find data or navigate to specific dashboard sections.
- Notification & User Profile Management: Display system notifications with badge counts and provide a user avatar dropdown for accessing profile settings and management options.
- Company Directory Display: Render a clear list of companies within the sidebar navigation, each featuring a small colored dot or logo placeholder for quick identification.

## Style Guidelines:

- Primary interactive color: A deep and vibrant blue (#2563EB) selected to convey professionalism and clarity in a data-centric environment. This bold hue stands out against the light background for key interactive elements.
- Background color: An extremely light, almost white, subtle blue (#F0F4FA). Its high brightness and low saturation ensure a clean, airy feel that promotes readability and focuses attention on content in light mode, complementing the primary blue.
- Accent color: A soft, brighter cyan (#84CBDB). This color provides a refreshing contrast while remaining harmonious with the primary blue, offering a secondary highlight for statuses or subtle call-outs, adhering to an analogous color scheme.
- Body and headline font: 'Inter' (sans-serif), chosen for its excellent readability across all sizes, neutral aesthetic, and modern appearance, aligning with the clean and data-heavy application theme.
- Utilize clear and consistent iconography, drawing inspiration from modern icon libraries like Lucide (consistent with shadcn/ui). Employ simple visual cues such as colored dots or logo placeholders for company listings in the navigation.
- A minimal and spacious admin dashboard layout featuring a collapsible left sidebar with icon-only mode, dynamic navigation with structured sections and sub-listings, and a top bar housing breadcrumbs, Cmd+K global search, notifications, and user dropdown.
- Incorporate subtle and smooth animation transitions for sidebar expansion/collapse, global search modal interactions, and notification pop-ups, enhancing the user experience while maintaining a professional and unobtrusive feel.
