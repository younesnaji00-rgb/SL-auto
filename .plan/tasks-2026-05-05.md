## Locked assumptions

- **8 steps**, in this order:
  1. Missions créées — count of all dossiers in the user's compagnie scope (NO date filter for this step — it's the total, not "created in range")
  2. Expertise avant — `datePhotosAvant` set
  3. Expertise en cours — `datePhotosEnCours` set
  4. Expertise après — `datePhotosApres` set
  5. Accord — `lastStatusChange.status` ∈ ACCORD_BUCKET_MEMBERS (each dossier counted once; 2ème/3ème accord don't double-count because the count is per-dossier, not per-event)
  6. Facture validée — `dateFactureValide` set (denorm field added in prior session)
  7. Rapport validé — `directorValidated` is set on the dossier (existing field)
  8. Rapport déposé — `dateRapportDepose` set (existing, unchanged)
- **One number per step card** — drop the réalisé / non réalisé / bloqué ici triplet entirely.
- **Drop the bottleneck column** in the per-utilisateur tab.
- **Click step card → side drawer** slides out from the right with the list of dossiers currently in that step. Each row: dossier identifier (refExpert / matricule / assuré), author of that step, timestamp of that step.
- **Click dossier row in drawer → `router.push('/dossiers/${id}')`** (the dossier detail page).
- Date range filter applies to steps 2-8 only (a step's count includes only dossiers whose step timestamp falls in the range). Step 1 (Missions créées) ignores the date filter — it's the total in scope.
