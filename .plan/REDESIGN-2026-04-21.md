# SL Auto Redesign — Master Plan

Locked 2026-04-21. Blends the approved **Dashboard v3.html** design language (from Claude Design) with the `redesign-existing-projects` audit principles.

## 1. Locked design tokens (north star)

Every phase must conform to these. Anything outside the language goes back to the user, not a judgement call.

### Palette
| Token | Value (target) | Notes |
|---|---|---|
| `--background` | warm cream `oklch(0.985 0.003 95)` | replaces blue-tint `215 67% 97%` |
| `--foreground` | warm charcoal | no pure `#000` |
| `--surface-2` / `--border` | warm-neutral | user flagged cool borders felt "different" from warm bg |
| `--sidebar-background` | slightly warmer cream than main bg | distinct but same family |
| `--primary` | dark teal (CTAs, active states) | replaces default shadcn blue `222 83% 58%` |
| `--accent` | lighter mint-teal (selection highlight) | replaces cyan `191 51% 70%` |
| `--destructive` | muted red (<80% sat) | status dot for "refused" |
| status dots | amber / green / red / purple / orange | all muted, no neon |
| `--chart-1..5` | navy / powder-blue / near-black / orange / muted-teal | per v3 Répartition par Compagnie |

### Typography
- Variable weights 400/500/600/700 (keep current scale).
- Small uppercase group labels with `letter-spacing: 0.08em` ("ESPACE", "ANALYSE").
- `font-variant-numeric: tabular-nums` on counts, amounts, dates, matricules.
- `text-wrap: balance` on h1/h2, `text-wrap: pretty` on paragraphs.
- Font: **Outfit** (locked 2026-04-21). Load via `next/font/google` with weights 400/500/600/700. Remove the Google Fonts `<link>` from `src/app/layout.tsx`. Replace `'Inter'` in `tailwind.config.ts` `fontFamily.body` and `.headline`.

### Layout patterns from v3 to adopt
- Sidebar groups with uppercase labels (ESPACE / ANALYSE / future: ADMIN).
- Status list w/ color-coded count badges; selected row → teal background.
- Right-side detail drawer slides out on status selection (instead of route nav).
- Bottom analytics row: Changements Tous / Changements Statut / Répartition Compagnie.
- Global search bar with ⌘K indicator.

## 2. Hard constraints (no-go zones)

Carried from memory + scan:
- Firestore `onSnapshot` subscriptions and `serverTimestamp()` writes — untouched.
- Compagnie dropdowns stay unrestricted for every role (memory: `feedback_compagnie_scoping.md`).
- Firefox long-polling flag (`experimentalAutoDetectLongPolling: true`) stays.
- French copy preserved verbatim — no retranslation "improvements".
- PDF pipelines (`generate-rapport-pdf.ts`, editor `html2canvas`/`jspdf`) untouched.
- Email-generation on login setup (strip accents → `.` → `@sl-auto.app`) untouched.
- Auth gating at `/(app)/layout.tsx` untouched.
- No framework/library migrations. Tailwind stays v3, shadcn + Radix stay.

## 3. Execution phases

### Phase 1 — Foundation (low risk, high impact)
Files: `tailwind.config.ts`, `src/app/globals.css`, `src/app/layout.tsx`.
- Swap Google Fonts `<link>` in layout → `next/font`.
- Rewrite CSS vars in `globals.css` light + dark modes to match locked palette. Dark mode stays, but rebased on warm-neutral not cool.
- Enable tabular-nums utility + balance/pretty headings in globals.
- Recharts palette retuned via `--chart-*`.
- **Exit**: `npm run typecheck` passes, `npm run dev` boots, dark/light toggle still works, no visual regression in any route.

### Phase 2 — Interactive polish (medium risk)
- `src/components/ui/button.tsx` — pressed state `active:scale-[0.98]`, spring-ish easing.
- Focus-ring pass across input/select/checkbox/switch.
- Real empty states (icon + French line + CTA) replacing plain-text dashed boxes in `missions-tab.tsx`, dossier list, assignations list, utilisateurs.
- Skeleton variants that mirror actual shape (rows vs cards vs chart).

### Phase 3 — Critical surfaces (one PR per surface, ordered by business impact)
1. **Login** (`src/app/login/page.tsx`) — first impression. Preserve dual-mode setup logic + email generation.
2. **Dossier detail** (`src/app/(app)/dossiers/[id]/page.tsx` + 19+ tab files) — sticky scrollable tab bar, timeline stepper polish, modal chrome. Firestore hooks untouched.
3. **Dashboard** (`src/app/(app)/dashboard/page.tsx`) — adopt v3 layout literally: status list w/ badges + drawer, asymmetric analytics row. Recharts palette retuned.
4. **Utilisateurs** (`client-page.tsx`) — table density, confirm-delete treatment.
5. **Editor** (`src/app/editor/page.tsx`) — toolbar grouping + tool-active state only. Canvas logic untouched.

### Phase 4 — Responsive & micro-polish
- Sidebar collapse breakpoints, dossier tab overflow <1280px, modal mobile width.
- Tinted shadows (hue-matched to bg), subtle noise overlay on marketing-feeling surfaces.
- Replace any `height: 100vh` → `min-height: 100dvh`.

## 4. Rollout mechanics

- Branch per phase off `master`. Never push until user reviews diff.
- `npm run typecheck` between every chunk; stop loop on failure.
- After each Phase 3 surface, pause for user sign-off before next.
- No direct deploys to prod — use Firebase preview channels when ready to visually review.
